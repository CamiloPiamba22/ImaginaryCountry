¿Qué es Bootstrap y cómo lo usamos?

INTRO

Bootstrap es un framework de CSS y JavaScript que nos da componentes listos para usar: menús, botones, formularios, cuadrículas, etc. Solo añadiendo clases en el HTML, sin escribir casi CSS nosotros mismos.

En este proyecto usamos una versión personalizada (no el CDN estándar).

📁 Archivos incluidos

Archivo ¿Qué hace?
css/custom-bootstrap.css Es el CSS de Bootstrap compilado con nuestros colores y estilos personalizados (ver Sección 9).
js/bootstrap.fixed.js Es el JavaScript de Bootstrap (menú offcanvas, collapse, etc.). Lo llamamos "fixed" porque tiene una corrección para un error con el offcanvas.
scss/styles.scss El archivo Sass donde definimos colores de la marca y personalizamos variables antes de compilar.
HTML → index.html href="css/custom-bootstrap.css" rel="stylesheet">
src="js/bootstrap.fixed.js">
💡 Dato importante: Bootstrap necesita ambos: el CSS (estilos) y el JS (comportamiento interactivo). Sin el JS, el menú hamburguesa, el offcanvas y el collapse no funcionarían.
🔍 Para tus compañeros: Si quieres usar Bootstrap en otro proyecto, puedes descargarlo o usar un CDN. En nuestro proyecto lo compilamos a medida para tener solo lo necesario.

Sistema de Cuadrícula (Grid)

LAYOUT

El grid de Bootstrap divide la página en 12 columnas. Usando combinaciones de container → row → col-* maquetamos el contenido.

Veamos cómo se usa en nuestro index.html (líneas 48–62):

index.html (hero) class="container col-xxl-8 px-4 py-5 mt">
   class="row flex-lg-row-reverse align-items-center g-5 py-5">
    
     class="col-10 col-sm-8 col-lg-6">
       src="..." class="d-block mx-lg-auto img-fluid">
    

    
     class="col-lg-6">
       class="display-5 fw-bold lh-1 mb-3">...
    

  

🔎 Clase por clase

container Crea un contenedor centrado con máximo de ancho (responsive).
col-xxl-8 En pantallas extra extra grandes (≥1400px), el contenedor ocupa 8 de 12 columnas.
px-4 / py-5 Espaciado interno (padding): px = horizontal (left+right), py = vertical (top+bottom). Los números van de 0 a 5.
row Crea una fila que contiene columnas. Contrarresta el padding del contenedor y organiza el grid.
flex-lg-row-reverse En pantallas grandes (lg+), invierte el orden de las columnas. La imagen pasa a la derecha y el texto a la izquierda. ¡Muy útil!
align-items-center Centra verticalmente todas las columnas dentro de la fila.
g-5 Gutter = espaciado entre columnas. g-5 da el espacio máximo. Es como margin entre columnas.
col-10 col-sm-8 col-lg-6 Columnas responsive: ocupa 10 columnas en móvil, 8 en tablet (sm), 6 en escritorio (lg). Así se adapta a cada pantalla.
mx-lg-auto Margen horizontal automático → centra la imagen en pantallas grandes.
img-fluid Hace que la imagen nunca se desborde y se escale con el contenedor. ¡Imprescindible!

📊 Visualización: cómo se reparten las 12 columnas

col-6 · Imagen (escritorio)
col-6 · Texto (escritorio)

En escritorio: 6 cols + 6 cols = 12 ✓

col-8 · Imagen (tablet)
col-4 · Texto (tablet)

En tablet: 8 cols + 4 cols = 12 ✓

🎯 Regla de oro: La suma de las columnas dentro de una fila debe dar 12. Si pones col-6 + col-6 = 12. Si pones col-4 + col-4 + col-4 = 12. Y así.

Barra de Navegación (Navbar)

NAV

La navbar es el menú superior. Se vuelve un menú hamburguesa en móvil y se despliega con offcanvas en lugar del clásico menú desplegable.

index.html líneas 13–46 class="navbar navbar-expand-lg fixed-top bg-secondary">
   class="container-fluid">
     class="navbar-brand text-primary" href="#">
       src="..." class="d-inline-block align-text-top">
       class="fs-2 fw-bold lh-1">República de Amargia
    
     class="navbar-toggler" data-bs-toggle="offcanvas">
       class="navbar-toggler-icon">
    
    
  

🔎 Clase por clase

navbar Activa los estilos de barra de navegación de Bootstrap.
navbar-expand-lg La navbar se muestra horizontal en pantallas grandes (lg+). En móvil se oculta y aparece el botón hamburguesa.
fixed-top Fija la barra arriba de todo y se queda pegada al hacer scroll. Atención: necesita un mt (margin-top) en el contenido de abajo para no taparlo.
bg-secondary Le da el color de fondo secundario (azul oscuro en nuestro caso). Las clases bg-* son colores contextuales de Bootstrap.
container-fluid Contenedor que ocupa todo el ancho disponible (a diferencia de container que tiene un máximo).
navbar-brand Estiliza el logo/nombre de la marca. Generalmente es un o .
text-primary Color de texto primario (verde claro en nuestro tema). Las clases text-* cambian el color del texto.
fs-2 / fw-bold / lh-1 fs-2 = tamaño de fuente nivel 2, fw-bold = negrita, lh-1 = interlineado mínimo (1 = compacto).
navbar-toggler El botón ☰ (hamburguesa) que aparece en móvil. Bootstrap lo estiliza automáticamente.
navbar-toggler-icon El icono ☰ en sí (tres rayitas). Bootstrap lo genera con CSS.
⚠️ Cuidado con fixed-top: Al usar fixed-top, la barra se superpone al contenido. Por eso en nuestro index.html hay una clase mt (margin-top) en el primer contenedor (línea 48). ¡Si no le pones margen, el contenido queda detrás de la navbar!
🔗 data-bs-toggle="offcanvas": En lugar del menú desplegable clásico, nuestro proyecto usa offcanvas (panel lateral). Lo explicamos en la siguiente sección.
4

Menú Offcanvas (panel lateral)

MÓVIL

Cuando pulsamos el botón hamburguesa ☰ en móvil, en lugar de un menú que se despliega hacia abajo, se abre un panel lateral desde la derecha. Eso es el Offcanvas de Bootstrap.

index.html líneas 22–44 class="offcanvas offcanvas-end" tabindex="-1" id="navbarOffcanvasLg">
   class="offcanvas-header">
     class="offcanvas-title">...
     class="btn-close btn-close-white" data-bs-dismiss="offcanvas">
  

   class="offcanvas-body">
     class="navbar-nav">
       class="nav-item">...
    
  

🔎 Clase por clase

offcanvas Activa el componente Offcanvas. Por defecto está oculto.
offcanvas-end El panel se desliza desde la derecha. También existe offcanvas-start (izquierda), offcanvas-top, offcanvas-bottom.
offcanvas-header Cabecera del panel con título y botón cerrar (×).
offcanvas-title Estiliza el título dentro del offcanvas.
btn-close El botón × para cerrar. Con btn-close-white se vuelve blanco (para fondos oscuros).
data-bs-dismiss="offcanvas" Atributo que le dice a Bootstrap: «al hacer clic, cierra el offcanvas».
offcanvas-body El contenido del panel (los enlaces del menú).
navbar-nav Estiliza la lista
    como navegación de navbar.
nav-item / nav-link nav-item es cada elemento, nav-link estiliza el enlace interno. active marca el enlace actual, disabled lo deshabilita.
🐛 Error conocido: Bootstrap tiene un bug en ciertas versiones donde el offcanvas dentro de la navbar no se cierra correctamente al hacer clic en un enlace. Por eso usamos bootstrap.fixed.js — es una versión parcheada que corrige ese problema.

Utilidades de Bootstrap

CLASES

Bootstrap tiene cientos de clases utilitarias que controlan una sola propiedad. Son rápidas de usar y evitan escribir CSS.

🎨 Colores de fondo y texto

Clase ¿Qué hace? En nuestro proyecto
bg-secondary Fondo azul oscuro Navbar (header)
bg-warning Fondo amarillo Sección del formulario
bg-success Fondo verde Sección del himno y botón "Submit"
text-primary Texto verde claro Título "Hola" y nombre en navbar
text-light Texto blanco Parte del título "República de Amargia"
text-secondary Texto azul oscuro Párrafo explicativo
text-dark Texto casi negro Texto dentro del collapse

📏 Espaciado (margin & padding)

Fórmula: {propiedad}{lado}-{tamaño}

Clase Significado Equivale a
p-5 Padding en los 4 lados · tamaño 5 padding: 3rem !important
pt-5 Padding-top (arriba) · tamaño 5 padding-top: 3rem
pb-5 Padding-bottom (abajo) · tamaño 5 padding-bottom: 3rem
px-4 Padding horizontal (izq + der) · tamaño 4 padding-left/right: 1.5rem
py-5 Padding vertical (arriba + abajo) · tamaño 5 padding-top/bottom: 3rem
mt-5 Margin-top · tamaño 5 margin-top: 3rem
mb-3 Margin-bottom · tamaño 3 margin-bottom: 1rem
📐 Escala de tamaños: 0 = 0, 1 = 0.25rem, 2 = 0.5rem, 3 = 1rem, 4 = 1.5rem, 5 = 3rem. ¡Fácil!

🔤 Tipografía

Clase Efecto
display-5 Texto grande y llamativo (como un título hero)
fw-bold Font-weight: bold (negrita)
fs-2 Font-size nivel 2 (bastante grande)
lh-1 Line-height: 1 (interlineado muy compacto)
lead Texto destacado, un poco más grande (1.125rem)

🔄 Otras utilidades populares

Clase ¿Qué hace? Ejemplo en el proyecto

Botones

BTN

Los botones de Bootstrap se crean con la clase btn más un color contextual. Veamos los que tenemos en el proyecto:

index.html líneas 57–58 y 80 y 101 type="button" class="btn btn-primary btn-lg px-4 me-md-2">Principal

type="button" class="btn btn-outline-secondary btn-lg px-4">Por defecto

type="submit" class="btn btn-primary bg-success shadow">Submit

type="button" class="btn btn-primary bg-success shadow" data-bs-toggle="collapse">Leer más...

🔎 Clase por clase

btn Clase base para todos los botones. Sin esto no hay estilo de botón.
btn-primary Color primario (verde claro en nuestro tema). Fondo verde claro con texto oscuro.
btn-outline-secondary Versión "outline": solo borde, sin relleno. Al hacer hover se rellena del color secundario (azul oscuro).
btn-lg Versión grande del botón (más padding y texto más grande). También existe btn-sm (pequeño).
me-md-2 Margin-right (margin-end) en pantallas medianas+. Separa el botón "Principal" del "Por defecto".
🎨 ¿Dos colores en un botón? En el formulario ves btn btn-primary bg-success shadow. Aquí btn-primary da el estilo base, pero bg-success sobrescribe el color de fondo a verde. Bootstrap permite combinar clases para personalizar sobre la marcha.
🧪 Experimenta: Cambia btn-primary por btn-secondary o btn-warning y verás cómo cambia el color al instante, sin escribir CSS.

Formularios

FORM

Bootstrap estiliza los formularios con clases específicas para inputs, labels, checks, etc.

index.html líneas 66–82 class="container-sm pt-5 pb-5">
   class="mb-3">
     class="form-label">Email address
     type="email" class="form-control">
     class="form-text">We'll never share...

  

   class="mb-3 form-check">
     class="form-check-input" type="checkbox">
     class="form-check-label">Check me out
  

🔎 Clase por clase

container-sm Contenedor con ancho máximo pequeño (sm). Así el formulario no se estira demasiado.
mb-3 Margin-bottom de tamaño 3 (1rem). Separa cada grupo de formulario del siguiente.
form-label Estiliza la etiqueta del campo. Bootstrap le da padding, color y peso de fuente específicos.
form-control Clase principal para inputs, selects y textareas. Les da bordes, padding, y el ancho completo.
form-text Texto de ayuda debajo del input (letra más pequeña, color gris).
form-check Contenedor para checkboxes y radios. Los estiliza correctamente.
form-check-input El checkbox en sí. Bootstrap lo embellece y le da el color del tema.
form-check-label La etiqueta del checkbox, alineada correctamente.
